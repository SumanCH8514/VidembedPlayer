VidEmbed Auto Stream Developer Documentation

Learn how to integrate the high-performance VidEmbed Auto Player on your web application. Features automated multi-CDN edge failover, custom dual-tone watermarking, adaptive HLS quality streaming, multi-audio selection, and native mobile gestures.

Overview

VidEmbed Auto Stream delivers an automated streaming interface capable of resolving movies and television series using either TMDB (The Movie Database) or IMDb identifiers.

Zero Hardcoded Credentials: All media resolution, manifest parsing, and failover health checks are handled on the edge without exposing secret API keys or third-party provider tokens on the client browser.

Architecture & Failover Pipeline

The player utilizes a two-tier streaming pipeline ensuring maximum availability:

Tier Delivery Mechanism Capabilities Behavior
Tier 1: Castle Direct HLS Direct M3U8 Stream Manifests 1080p, 720p, 480p, 360p adaptive bitrate, multi-channel audio tracks, WebVTT subtitles Instant playback via native HTML5 video and Hls.js with zero popup advertisements.
Tier 2: Edge CDN Failover Multi-Node Fallback 12 Distributed global streaming nodes (VidSrc, 2Embed, Toulouse, Castle, etc.) Automatic real-time latency pinging and silent edge redirection if any source suffers degradation.

URL Formats & Endpoints

The platform supports both standardized query parameter routing and clean path routing.

Pattern Endpoint Example Result
Movie Embed /auto?type=movie&id=1236045&embed=1 Direct full-viewport embed player for the specified movie.
TV Episode Embed /auto?type=tv&id=94997&s=1&e=2&embed=1 Direct full-viewport embed player for Season 1, Episode 2.
Clean Embed Path /auto/embed?type=movie&id=1236045 Automatically resolves into embed mode without requiring embed=1.
IMDb ID Query /auto?type=movie&id=tt1375666&embed=1 Resolves IMDb ID into the corresponding title and streams automatically.
Studio Mode /auto?type=movie&id=1236045 Loads the interactive studio page with metadata inspection and telemetry.

Query Parameters Reference

Customize video behavior, player styling, and failover parameters with URL query arguments.

Parameter Status Type Default Description
type Required "movie" | "tv" "movie" Specifies the media content format.
id Required string | number none TMDB integer ID (e.g. 1236045) or IMDb alphanumeric string (e.g. tt1375666).
s / season Optional number 1 Season index number for TV series.
e / episode Optional number 1 Episode index number for TV series.
brand Optional string "SumanMovies" Watermark pill brand label. Automatically formatted into a sleek dual-tone pill.
color Optional string "0ea5e9" Player UI theme accent color hex code without # (e.g. 38bdf8, ef4444).
fit Optional "contain" | "cover" | "fill" "contain" Video aspect ratio fitting mode. contain letterboxes; cover zooms; fill stretches.
autoplay Optional 1 | 0 0 Initiates automatic video playback upon load (often requires muted=1 on mobile browsers).
muted Optional 1 | 0 0 Mutes audio volume on initial player load.
embed Optional 1 | 0 0 Activates standalone embed player mode, hiding all studio and customizer chrome.

React & Next.js (TypeScript)

A production-ready React component with TypeScript props validation:

AutoEmbedPlayer.tsx 
import React from 'react';

interface AutoEmbedPlayerProps {
  type: 'movie' | 'tv';
  id: string | number;
  season?: number;
  episode?: number;
  brand?: string;
  color?: string;
  autoplay?: boolean;
  muted?: boolean;
  fit?: 'contain' | 'cover' | 'fill';
  className?: string;
}

export const AutoEmbedPlayer: React.FC<AutoEmbedPlayerProps> = ({
  type,
  id,
  season = 1,
  episode = 1,
  brand = 'SumanMovies',
  color = '0ea5e9',
  autoplay = false,
  muted = false,
  fit = 'contain',
  className = ''
}) => {
  const params = new URLSearchParams({
    type,
    id: String(id),
    brand,
    color: color.replace('#', ''),
    fit,
    embed: '1'
  });

  if (type === 'tv') {
    params.set('s', String(season));
    params.set('e', String(episode));
  }
  if (autoplay) params.set('autoplay', '1');
  if (muted) params.set('muted', '1');

  const embedUrl = `https://yourdomain.com/auto?${params.toString()}`;

  return (
    <div
      className={className}
      style={{
        position: 'relative',
        width: '100%',
        aspectRatio: '16 / 9',
        backgroundColor: '#000',
        borderRadius: '12px',
        overflow: 'hidden'
      }}
    >
      <iframe
        src={embedUrl}
        title="VidEmbed Auto Stream Player"
        loading="lazy"
        allow="autoplay; fullscreen; picture-in-picture; encrypted-media"
        allowFullScreen
        style={{
          position: 'absolute',
          top: 0,
          left: 0,
          width: '100%',
          height: '100%',
          border: 'none'
        }}
      />
    </div>
  );
};

Vue 3 Component

Single-file component implementation using Vue 3 Composition API:

AutoPlayer.vue 
<script setup lang="ts">
import { computed } from 'vue';

const props = withDefaults(defineProps<{
  type?: 'movie' | 'tv';
  id: string | number;
  season?: number;
  episode?: number;
  brand?: string;
  color?: string;
  autoplay?: boolean;
}>(), {
  type: 'movie',
  season: 1,
  episode: 1,
  brand: 'SumanMovies',
  color: '0ea5e9',
  autoplay: false
});

const embedUrl = computed(() => {
  const q = new URLSearchParams({
    type: props.type,
    id: String(props.id),
    brand: props.brand,
    color: props.color.replace('#', ''),
    embed: '1'
  });
  if (props.type === 'tv') {
    q.set('s', String(props.season));
    q.set('e', String(props.episode));
  }
  if (props.autoplay) q.set('autoplay', '1');
  return `https://yourdomain.com/auto?${q.toString()}`;
});
</script>

WordPress & CMS Embeds

Easily embed into WordPress using the Custom HTML Block, Elementor HTML Widget, or a PHP Shortcode.

functions.php WordPress Shortcode 
function vidembed_auto_shortcode($atts) {
    $a = shortcode_atts(array(
        'type'    => 'movie',
        'id'      => '1236045',
        'season'  => '1',
        'episode' => '1',
        'brand'   => 'SumanMovies',
        'color'   => '0ea5e9'
    ), $atts);

    $url = 'https://yourdomain.com/auto?type=' . esc_attr($a['type']) .
           '&id=' . esc_attr($a['id']) .
           ($a['type'] === 'tv' ? '&s=' . esc_attr($a['season']) . '&e=' . esc_attr($a['episode']) : '') .
           '&brand=' . esc_attr($a['brand']) .
           '&color=' . esc_attr($a['color']) .
           '&embed=1';

    return '<div style="position:relative;width:100%;aspect-ratio:16/9;background:#000;border-radius:12px;overflow:hidden;">
        <iframe src="' . esc_url($url) . '" style="border:none;width:100%;height:100%;position:absolute;top:0;left:0;" allow="autoplay; fullscreen; picture-in-picture; encrypted-media" allowfullscreen></iframe>
    </div>';
}
add_shortcode('vidembed_auto', 'vidembed_auto_shortcode');

Best Practices & Security

Recommended policies for embedding iframes securely into your website:

Browser Autoplay Requirements: Modern browsers (Google Chrome, Apple Safari, Mozilla Firefox) require videos with autoplay=1 to also have muted=1, otherwise the browser will block automated playback until user interaction occurs.

If your website employs Content Security Policy (CSP) headers, ensure your frame-src directive permits your streaming domain:

Content-Security-Policy Header 
Content-Security-Policy: frame-src 'self' https://yourdomain.com;

FAQ & Troubleshooting

Can I pass IMDb IDs instead of TMDB IDs?
Yes. You can pass any IMDb title identifier (e.g. id=tt1375666). The system automatically queries the edge resolver and Cinemeta index to locate the correct stream and artwork without any code changes.
What happens if the primary Castle server goes offline?
The player's automated failover engine instantly switches to the next reachable high-speed edge CDN node (VidSrc, Toulouse, etc.) within milliseconds without interrupting the user session.
Are there advertisements or popups on Castle Direct HLS?
No. Castle Direct HLS feeds stream directly over native HTTP Live Streaming without any third-party ad networks, popunders, or redirection scripts.
